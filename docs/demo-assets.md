# Demo assets and production notes

The narrated walkthrough is 96.88 seconds, 1920×1080, H.264 video with AAC narration. It includes burned-in English subtitles and a separate WebVTT caption track.

- App footage: genuine screenshots and successive replay frames from the working synthetic-data application, edited and cropped for readability. The clip is an edited screen-capture walkthrough, not a claim of continuous screen recording.
- Cards and layout: created specifically for Agora Match. The diagram describes an optional workflow and is not a fabricated live execution trace.
- Voice: synthesized with [Piper](https://github.com/OHF-Voice/piper1-gpl), using [en_US-ljspeech-high](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ljspeech/high/MODEL_CARD). The voice model card identifies the [LJ Speech](https://keithito.com/LJ-Speech-Dataset/) source dataset as public domain. The model repository supplies its own license. No model weights or Piper runtime are distributed with the application.
- Text: original product explanation. The transcript is in `static/media/agora-match-demo.vtt` on the hosted site; a copy is included in this documentation directory.
- Music and football footage: none. No Premier League club badges, real player images, or broadcast clips are used.

The video is hosted alongside the app for review. The competition still requires its own public video URL on an accepted video platform.
