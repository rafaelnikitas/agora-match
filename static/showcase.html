What you are seeing

Genuine captures of the functioning app, edited into a narrated walkthrough with readable close-ups and captions. The replay uses successive captured frames. All teams, players, history, events, positions, and sensor readings are fictional. Narration is synthesized; no match footage or music is used.

How the AI works

The Azure app uses managed identity to invoke GPT-OSS-120B in Microsoft Foundry. Three specialist stages share that model: match analyst, audience narrator, and evidence reviewer. Custom Python code orchestrates them, preserves canonical fact values and source IDs, and allows one controlled correction before an evidence fallback. The recorded answers show actual model execution. Read the live verification report.

Data and evaluation limits

The recorded acceptance run passed 21 expected topic/evidence checks with 21 fresh AI answers; five drafts recovered through a bounded correction. These fixed development cases do not establish semantic accuracy or superiority over a single-agent approach. Human quality review remains pending. Player positions are minute-sampled; the ball path is illustrative interpolation constrained by event locations. Coach cues support review and do not diagnose fatigue or establish marking responsibility. The separate static fallback uses deterministic answers.
