What you are seeing

Authentic captures from the functioning app, edited for clarity. Teams, players, history, events, and telemetry are fictional. Narration is synthesized and captions are included. No match footage or music is used.

AI execution status and limits

The public demo uses deterministic responses. The source includes an optional Microsoft Foundry analyst, narrator, and reviewer workflow. Live model evaluation and Azure deployment remain unverified. Local regression checks are not a live LLM accuracy score. Player positions are minute-sampled; the second-by-second ball path is illustrative interpolation constrained by event locations.
